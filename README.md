# Altum Legal — лендинг

Одностраничный сайт юридической компании Altum Legal (Бишкек).
React 19 + TypeScript + Vite, собственная дизайн-система на CSS.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # продакшн-сборка в dist/
npm run preview  # локальный просмотр собранной версии
```

Для публикации достаточно залить содержимое `dist/` на любой статический
хостинг (Netlify, Vercel, Cloudflare Pages, обычный nginx).

## Где что править

| Что | Файл |
|---|---|
| **Весь текст, цены, контакты** | `src/data/content.ts` |
| Цвета, шрифты, размеры, отступы | `src/styles/tokens.css` |
| Базовая типографика и сброс | `src/styles/base.css` |
| Кнопки, поля, иконки, анимации появления | `src/styles/ui.css` |
| Вёрстка секций | `src/styles/sections.css` |
| Разметка секций | `src/sections/*.tsx` |
| Иконки (SVG, рисуются кодом) | `src/components/Icons.tsx` |
| Title, description, Open Graph, микроразметка | `index.html` |

Почти всё, что попросит поменять заказчик (цены, формулировки, телефон,
порядок услуг), лежит в `src/data/content.ts` — трогать компоненты не нужно.

## Фирменный стиль

Взят из брендбука компании без отклонений:

- **Цвета:** `#1E1E1E`, `#2F2B27`, `#F4F1EC`, `#5B0F1A` (бордо), `#B08B5A` (золото)
- **Шрифты:** Cormorant Garamond (заголовки), Montserrat (текст) — подключены с Google Fonts
- **Логотип:** знак «A» вырезан из исходного PDF в прозрачный PNG
  (`public/logo-mark.png`), словесная часть набрана шрифтом — так она
  остаётся резкой на любом экране и индексируется поисковиками.
  Полный лок-ап для подвала — `public/logo-lockup.png`.
- Фавиконки и Open Graph-картинка сгенерированы из логотипа.

## Структура страницы

Герой → бегущая строка направлений → О компании → Услуги → Преимущества →
Как мы работаем → Ценности → Стоимость → Контакты → Подвал.

## Форма заявки

Бэкенда нет: форма проверяет поля и открывает WhatsApp с готовым текстом
заявки (`wa.me/996555905001`), либо почтовый клиент по кнопке
«отправьте письмом». Это рабочий вариант для старта.

Если понадобится приём заявок на сервер (CRM, Telegram-бот, почта) —
менять надо только `onSubmit` в `src/sections/Contact.tsx`.

## Анимации

- Появление блоков при скролле — IntersectionObserver + CSS-переходы
  (`src/components/Reveal.tsx`)
- Золотая линия в блоке «Как мы работаем» растёт по мере прокрутки
  (`motion`, `useScroll`)
- Параллакс знака «A» в герое, бегущая строка, поэтапный вход первого экрана
- Всё отключается при `prefers-reduced-motion: reduce`
